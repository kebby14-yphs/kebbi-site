# 凱比實測：卑南語發音比對與波形疊合

2026-11-04 · Claude

「凱比教卑南語」App 接上筆電的本機 AI 大腦，第一次用**凱比自己的麥克風**做卑南語發音比對，並做了即時波形疊合頁面，讓老師看到學生的聲音和官方示範哪裡不一樣。

![波形疊合：sinabalran（早安）相似度 50%](notes/img/2026-11-04-pronounce-waveform.png)

**藍色＝官方辭典示範、橘色＝學生（測試者）的聲音、紅色＝易錯的部分。** 上圖是照實際秒數疊合，下圖是用 DTW 把學生的聲音依發音位置對齊到示範的時間軸。

## 運作流程

1. 摸凱比身體（或老師在筆電網頁點詞語）→ 凱比用中文介紹 → 播官方發音 → 做動作 → 「換你說說看！」
2. 凱比錄下學生的聲音，經 USB（`adb reverse`）傳到筆電，**不經網路**
3. 筆電大腦比對學生錄音和官方發音（不轉文字，直接比聲音）→ 相似度 0~100%
4. 凱比用自己的聲音給回饋，畫面顯示相似度；筆電網頁同步顯示波形

**過關規則（老師訂）：相似度 50% 以上就稱讚並自動教下一個詞；不到 50% 就提示、重播官方發音、再試，直到過關。** 學生卡住時，老師可在網頁點別的詞，凱比立刻換過去。

## 相似度怎麼算

| 步驟 | 做法 |
|---|---|
| 整理聲音 | 降噪 → 只留最主要的一段說話 → 音量正規化（忽略喀嚓聲之類的尖刺） |
| 小孩 vs 大人 | 聲道長度正規化：把學生聲音往下移幾種音高，取最接近的 |
| 聲音特徵 | MFCC（聲音的頻率形狀）＋ wav2vec2（AI 聽到的「音」） |
| 對齊 | DTW：念得快或慢都能一格一格對上 |
| 換算分數 | 每個詞事先用官方錄音校正「說對大概差多少、說錯大概差多少」，學生落在中間的位置就是相似度 |
| 易錯的部分（紅色） | 每 10 毫秒比一次，差異超過「說對時的平均」1.3 倍、持續 50 毫秒以上 |

凱比的回饋**只說中文**（例如「差一點點！結尾再注意一下」），卑南語一律播官方錄音。原本回饋裡有卑南語拼音，被凱比的中文語音念錯，老師測試時發現後已改掉，避免學生學到錯的發音。

## 發現的問題與修正

| 發現 | 原因 | 處理 |
|---|---|---|
| 一開始每次都「再試一次」 | 凱比麥克風底噪大，訊噪比只有約 10~16 dB | 改善切靜音，只留最主要的一段說話 |
| 錄音切完還有 3~5 秒（官方只有 1~2 秒） | 舊的切靜音門檻被雜音騙過 | 改用相對底噪的分貝門檻 |
| 學生聲音的波形被壓得很小 | 錄音裡有喀嚓聲尖刺，音量以最大值為準 | 改用第 99.5 百分位當基準 |
| **模擬測試最好的方法（融合，AUC 0.995）到真實凱比反而變差** | 凱比麥克風的音色和官方錄音差很多，MFCC 被音色主導 | 真實錄音中 wav2vec2 表現最好（inabayan 6 次都排第 1）；之後要用真實錄音重新校正 |
| 偶爾連不到筆電大腦 | USB 插拔或 adb 重啟會清掉 `adb reverse` | 加上自動檢查、斷了自動接回 |

**最重要的結論：模擬資料不能取代真實資料。** 用官方錄音變形做的模擬測試很漂亮，但換成凱比的麥克風和真人聲音，準確度明顯下降。

## 下一步

1. 收集「已知念對」的真實錄音（老師或族語老師對凱比每詞念幾次），用來重新校正相似度和 50% 過關線
2. 比較凱比三種錄音模式（原始、通話模式、一般麥克風），找收音最清楚的
3. 加上**音素比對**：把羅馬拼音轉成音標，指出是哪個音（例如 dr、lr）念錯，讓紅色區塊標上字母
4. 請族語老師確認拼音轉音標的對照表
