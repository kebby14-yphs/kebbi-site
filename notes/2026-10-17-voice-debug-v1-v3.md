# 語音偵錯 v1 / v3 程式分析

**結論：**兩版都可能讓凱比一直重複「請再說一次」而停不下來。v3 的「先把辨識結果唸出來」是正確的偵錯方向，v4 應該在這個基礎上加上次數上限和多種答案。

## v1：測試卑南語 `inavayan`

流程：凱比說「請說：inavayan」→ 聽 → **直到「聽到的內容」完全等於 `inavayan`** 才結束，否則一直請學生重說。

| 問題 | 影響 |
|---|---|
| 用「完全相等」比對卑南語詞 | 凱比的語音辨識只懂中文 / 英文，`inavayan` 會被辨識成中文同音字或其他字串，幾乎不可能完全相等 → **迴圈停不下來** |
| 成功提示寫成「辨識到 123，做得很好」 | 是從另一個測試複製過來沒改，應該是 `inavayan` |
| 有一個「錄音」積木沒接到流程上 | 不會執行，可以刪掉或接上 |
| 沒有次數上限 | 學生講不出來時沒有出口 |

## v3：讀出辨識結果、測試 `123`

流程：凱比說「請說 123，接著我會讀出辨識結果」→ 聽 → **把辨識結果唸出來** → 直到結果「包含」`123` 才結束。

改進：

- 唸出辨識結果，終於能知道凱比到底聽到什麼
- 用「包含」取代「完全相等」，比較寬鬆

還有的問題：

- `123` 可能被辨識成「一二三」或「一百二十三」，就不會「包含 123」
- 一樣沒有次數上限
- 什麼都沒聽到時，凱比會唸出空白

## v4 建議

1. **先收集資料：**用 v3 的「唸出辨識結果」讓幾位學生各說幾次 `inavayan`，記下凱比實際聽成什麼
2. **接受清單：**把常見的辨識結果都列進去，結果「包含其中任何一個」就算成功
3. **次數上限：**最多試 3 次，之後鼓勵學生並示範正確發音，繼續下一題
4. **修正提示句：**成功時說「辨識到 inavayan」
