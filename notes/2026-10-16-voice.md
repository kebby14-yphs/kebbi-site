# 凱比為什麼不能直接用 Android 語音

**結論：**凱比沒有安裝標準 Android 語音引擎（TTS），要讓凱比用自己的聲音說話，必須透過 NUWA SDK。

## 觀察

- `settings get secure tts_default_synth` 回傳 `null`，系統沒有預設語音引擎
- 凱比的說話功能由 NUWA 自己的語音服務（`com.nuwarobotics.service.voice.service`）提供
- 凱比的遠端 SDK 服務（`nuwasdkcontrolagent` 的 `RemoteSDKService`）沒有開放可以從電腦直接連線的 TCP 連接埠

## 目前的替代做法

電腦用 Windows 語音（Microsoft Hanhan，zh-TW）合成語音檔，用 `adb reverse` 讓凱比的 NuwaBrowser 開啟電腦上的網頁，網頁顯示文字並播放語音。

優點是不需要安裝任何東西到凱比；缺點是聲音不是凱比的，也不能配合動作。

## 正式做法

用 NuwaSDK 寫 Android App：

```java
mRobotAPI = new NuwaRobotAPI(this, new IClientId(getPackageName()));
// 等 onWikiServiceStart() 回呼後才能呼叫
mRobotAPI.startTTS("你好，我是凱比", Locale.CHINESE.toString());
```
